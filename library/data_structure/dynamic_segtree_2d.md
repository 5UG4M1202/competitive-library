# 動的二次元セグメント木

`cp::DynamicSegtree2D<M>` は整数座標の固定範囲における一点上書きと矩形集約を提供し、更新される点を後からオンラインで追加できます。x 方向は必要になった節点だけを確保する動的セグメント木、y 方向は一本道を圧縮した二分木で集約します。`M::op` は結合的かつ可換、`M::id()` は単位元である必要があります。逆元は不要です。

コード欄の「提出用の利用例」は、ライブラリ本体・下の `Sum`・`main()` をまとめてコピーできます。この例に外部ライブラリは不要です。`main()` は問題の入出力に合わせて変更してください。Monoid を自分で作る手順は [Monoid 定義ガイド](monoid_segtree.md) を参照してください。

```cpp
#include "library/data_structure/dynamic_segtree_2d.hpp"
#include <cassert>
struct Sum {
  using value_type = long long;
  static value_type id() { return 0; }
  static value_type op(value_type a, value_type b) { return a + b; }
};
int main() {
  cp::DynamicSegtree2D<Sum> tree(-100, 101, -100, 101);
  tree.set(1, 3, 4); tree.set(2, 5, 6); // 座標は事前登録不要
  assert(tree.prod(1, 3, 3, 6) == 10);
  tree.set(1, 3, tree.get(1, 3) + 2); // 一点加算
  assert(tree.get(1, 3) == 6);
}
```

構築時の引数は管理範囲 `[xl,xr) × [yl,yr)` で、それぞれ `long long` の整数、下端 < 上端が必要です。`set` / `get` の点はこの範囲内に限ります。上端自体は含まれず、`LLONG_MAX` 自体を座標として登録することはできません。範囲幅の差を符号付き整数で計算せずに分割するため、`[LLONG_MIN, LLONG_MAX)` も指定できます。未設定の点は `M::id()` です。同一座標への `set` は上書きします。`prod(xl,xr,yl,yr)` は半開矩形を集約し、管理範囲外を含んでもよく、空・逆転区間なら単位元です。

範囲幅を `W_x`、座標のビット数を `B = 64` とすると、一点上書きと矩形集約は `O(log(W_x+1) B)`、一点取得は `O(log(W_x+1)+B)`。`K` 個の異なる更新座標を使った後の空間は最大 `O(K log(W_x+1))` です。各 x 節点の y の圧縮木は、そこに登録された異なる y 座標数を `k` とすると最大 `2k-1` 節点です。定数倍は小さくないため、大きな入力ではメモリ計測が必要です。単位元への上書きでも節点を解放せず、読み取りでは新規確保しません。各種 Monoid 演算・コピーは定数時間と仮定し、値と中間演算の範囲は呼び出し側で管理します。

参考として GCC 11.4 `-O2`・WSL2 で、`[0,2^30)` の一様乱数 1 万点を追加し全体を一度集約すると、最大 RSS は約 29 MiB でした。同条件の座標登録型は約 10 MiB です。プロセス全体の値であり、入力分布やコンパイラにより変わります。

`M::op` や値のコピーが更新途中に例外を送出した場合、それ以前に変更した節点は復元しません。例外後の木は再構築してください。`Rational128` の計算範囲外による例外も含みます。

既存の一次元 `dynamic_lazy_segtree` は区間作用用の API・制約を持つため、ここでは一点上書き・集約に必要な動的セグメント木と圧縮二分木を内部実装しています。分数など連続的な座標には未対応です。事前に全更新座標が分かる場合は [座標登録型](sparse_segtree_2d.md) の方が空間を抑えやすく、固定点でメモリや最近傍検索を重視する場合は [kd-tree](../geometry/integer_kd_tree.md) も候補です。

和と gcd のランダムな素朴比較、範囲境界、同一点の再更新、分数値をローカル検証しています。
