# グリッド探索

長方形の格子を保持し、壁を避けて上下左右に移動したときの最短距離や到達可能なマスを求めます。辺に重みがある場合や、斜め移動を含む場合は別のアルゴリズム・設定が必要です。

```cpp
#include "library/graph/grid.hpp"
GRID<> grid(2, 3, '.');
grid.wall('#');
grid[0][1] = '#';
auto dist = grid.bfs(0, 0); // dist[0][2] == 4
grid.bfs_vis(0, 0);         // grid.vis に到達可能なマスを蓄積
```

座標は `(行, 列)` の0始まりで、高さ `H`・幅 `W` は非負です。`grid[i][j]` で値を読み書きし、`wall(value)` で通れない値を追加します。`bfs` は各マスの距離を返し、到達不能や壁は `GRID<T>::INF_VALUE`（`10^18`）です。始点が壁または範囲外なら、すべて到達不能の表を返します。最短距離はこの番兵より小さく、添字・サイズ・メモリがそれぞれの型に収まる必要があります。

`bfs_vis` は到達可能なマスを `vis` に追加します。訪問済みの始点や無効な始点では何もしません。別の探索を最初から行いたいときは `vis` を明示的に初期化するか新しい `GRID` を使います。`read(h,w,wall)` は標準入力から `h*w` 個の `T` を読み、`field` と `vis` を作り直して壁値を追加します。**既存の壁集合は消しません。** 入力が成功することが前提です。

`get_positions(value)` は一致する全座標を行優先順で返します。`get_start_goal(start,goal)` はそれぞれ最後に見つかった座標を返します。見つからない場合も既定の `(0,0)` となり、実際の位置と区別できません。必要なら `get_positions` で個数を確認してください。`print(gap)` は標準出力に表示します。公開されている `field`、`vis`、`H`、`W` のサイズ関係を外部から壊さないでください。

格子の構築・`read`・`bfs`・`bfs_vis`・全探索する位置取得は `O(HW)`、距離・訪問表のメモリは `O(HW)` です（壁集合の操作が平均 `O(1)` と仮定）。`T` は壁集合用の `std::hash` と等値比較が必要で、使う操作に応じてストリーム入出力やコピー・代入を満たしてください。

従来の `cpptemplate` から分離し、既定構築後のサイズを0に初期化しました。また、同じ行数で幅を変更した `read` の範囲外アクセスと、無効または壁の始点からの `bfs` を修正しました。従来の `INF` マクロへの依存は `INF_VALUE` に置き換えています。従来部分の具体的な来歴は未確認で、Apache-2.0 は rrrriki の権利を持つ著作物性のある人による寄与に適用します。
