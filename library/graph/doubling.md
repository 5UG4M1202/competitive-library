# ダブリング

各頂点の次の頂点が1つ決まっているとき、同じ遷移を多数回繰り返した先を高速に求めます。複数の行き先から選ぶ一般的なグラフ探索とは用途が異なります。

```cpp
#include "library/graph/doubling.hpp"
std::vector<int> next{1, 2, -1};
Doubling<int> db(next, 100);
int a = db.jump(2, 0); // 2
int b = db.jump(3, 0); // -1（行き止まり）
```

`next[v]` は0以上 `N` 未満の頂点か、`invalid`（既定値 `-1`）です。番兵は有効な頂点番号と重ならない値にしてください。`T` の各値は `int` に表現できる必要があります。`jump(k, v)` の始点も有効な頂点か番兵です。`k=0` では始点を返し、途中で行き止まりになれば番兵を返します。

`max_k >= 0` は必要な歩数を表すビット数を決めます。`jump` の歩数 `k` は非負で、構築された `LOG` ビットに収まる必要があります。例えば `max_k=5` の場合は `LOG=3` で、`0 <= k <= 7` を扱えます。`max_k=0` でも `LOG=1` です。構築時の既定 `max_k` は `2^61`、`build(next)` による再構築時の既定は従来どおり `2^60` です。`LLONG_MAX` も指定できます。範囲や符号に関する `assert` は無効化できるため、リリースビルドでも呼び出し側が前提を守ってください。遷移先値や `N` の `int` への変換は検査しません。

頂点数を `N`、用意するビット数を `LOG` とすると、構築時間とメモリは `O(N LOG)`、1回の `jump` は `O(LOG)` です。0頂点でも構築でき、始点として番兵を返す場合に限り `jump` を使えます。
