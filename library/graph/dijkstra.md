# ダイクストラ法

非負の辺重みを持つ有向・無向グラフで、1つの始点から全頂点への最短距離を求めます。負辺があるグラフには使用できません。

```cpp
#include "library/graph/dijkstra.hpp"
Graph<long long> g(3);
g.add_directed_edge(0, 1, 4);
g.add_directed_edge(1, 2, 3);
auto dist = dijkstra(g, 0); // {0, 4, 7}
```

始点は `0 <= s < g.size()`、全ての辺の両端は有効で、重みは非負が前提です。`T` は順序・加算・減算と `numeric_limits<T>::max()` を扱える数値型を想定し、比較や演算が通常の非負数として成立する必要があります。未到達値は `numeric_limits<T>::max()` で、ちょうどその値の距離も区別できません。オーバーフローする候補距離は無視します。表現可能な最短距離を区別するには、最短距離が番兵より小さいことが必要です。

頂点数 `V`、隣接リスト中の辺数 `E` に対し、遅延削除する優先度付きキューを使い、時間 `O(V+E+(E+1) log(E+1))`、追加メモリ `O(V+E)` です。並行辺がない通常のグラフでは `O((V+E) log V)` と表せます。経路そのものは返しません。
