# クラスカル法

グラフの辺から最小または最大の全域森の**重みの合計**を求めます。連結グラフなら全域木の重みです。ACL の `dsu` が必要です。

```cpp
#include "library/graph/kruskal.hpp"
Graph<long long> g(3);
g.add_edge(0, 1, 2);
g.add_edge(1, 2, 3);
g.add_edge(0, 2, 6);
auto minimum = kruskal(g);        // 5
auto maximum = kruskal(g, "max"); // 9
```

`"max"` のとき最大、それ以外の文字列は従来どおり最小を求めます。選択した辺や連結かどうかは返しません。入力が非連結の場合は各連結成分の全域木の和で、空グラフは `0` です。隣接リストの各辺を無向の接続として扱うため、有向グラフに対して有向全域木を求めるものではありません。無向辺を `Graph::add_edge` で追加した場合の両方向の重複は同じ接続として扱います。

頂点と辺の端点は有効範囲内で、頂点数は ACL の `int` に収まり、辺の比較と重みの加算ができることが必要です。全ての中間合計が `T` に収まることが必要で、オーバーフローは検出しません。頂点数 `V`、隣接リスト中の辺数 `E` とすると、時間 `O(V+E log(E+1))`、追加メモリ `O(V+E)` です。
