# 幾何ライブラリの設計

整数幾何と、浮動小数点を扱う幾何は別の部品として設計します。整数の向き・外積は有限幅での正確な判定とし、座標・中間値の範囲を要求します。浮動小数点版は long double と EPS による近似判定を使います。返却する距離なども近似値です。射影・交点は未実装です。浮動小数点の近似的な等値をソートの比較関数に無条件に適用しません。

最初の部品は [整数点と偏角](../library/geometry/integer_point.md) と [整数凸包](../library/geometry/integer_convex_hull.md) です。点の重複、ゼロベクトル、同方向、一直線上の境界点、ソートの回転開始位置、数値の幅は各 API の仕様に明記します。ABC481 E は偏角順と円環走査を使う利用例であり、同一直線上の点が存在しないというその問題の前提を明示します。

整数凸包への包含判定、最遠点対、最近点対も提供します。今後は、線分の位置関係と交差、多角形や円などを用途に応じて検討します。問題ごとの入出力はテスト側に置き、汎用 API の境界や返り値は別に決めます。各機能は対応する Library Checker などの実問題に加え、対象問題では出現しない退化入力と小さい例の素朴比較で検査します。

固定点集合の矩形集約・点列挙・最近傍は [整数版](../library/geometry/integer_kd_tree.md) と [実数座標版](../library/geometry/real_kd_tree.md) を提供します。[静的2次元 kd-tree の調査と設計案](kd-tree-design.md) も参照してください。

## 座標型と EPS

固定次元の `Point<T,N>` を使い、2次元は x・y と添字、その他の次元は添字でアクセスします。整数点は `int64_t`、実数点は `long double` です。共通の内積・距離二乗は明示した中間型を使います。整数の各中間結果、N 次元の部分和、実数の中間結果が表現範囲に収まる必要があります。

`Geometry2D` は既定 EPS `1e-10L` を持ち、コンストラクタで指定できます。点には EPS を持たせません。方向判定の EPS は直線からの距離として扱い、EPS を sort の比較器には使いません。EPS はあらゆる入力に適した誤差保証ではなく、退化・丸めにより凸包などの結果の整合性が崩れる場合があります。

実数 KD-tree の矩形は EPS を使わない半開境界です。共通点型は KD-tree の N 次元対応を意味しません。過去の double と Boost による多倍長版は今回の未公開変更内で long double 版に置き換えました。

速度の参考値として、同じ固定乱数の10万点を GCC 11.4 `-O2 -march=native`・WSL2 で処理したところ、long double 版の最近点対は約37 ms、最遠点対は約43 msでした。以前の Boost による格納済み double の厳密判定版では同じ生成条件でそれぞれ約848 ms・429 msでした。別時刻の各1回の測定であり、厳密な判定を行う旧版と近似判定の新版は保証が異なります。入力・環境で差が変わるため、性能や時間制限の保証ではありません。
