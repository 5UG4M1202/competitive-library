# 提出用テンプレートの入出力とマクロ

`cpp.json` の `cpptemplate` と `paizatemplate` は提出用の全体ひな形です。どちらも `bits/stdc++.h`、`__INCLUDE_LEVEL__` と `#include __FILE__` を使うため、対応するコンパイラと実ファイルへの保存が必要です。`cpptemplate` は AtCoder Library の include path と C++20 を必要とし、`USE_BOOST` を有効にした場合は Boost、`LOCAL` を有効にした場合は利用者の `debug.h` も必要です。`paizatemplate` のグラフ用 `dsu` はテンプレート内に含まれます。

`cpptemplate` の `ordered_set_less` は GNU libstdc++ PBDS の昇順・重複なし集合の alias で、標準 C++ のみの環境にはありません。`order_of_key(x)` は `x` 未満の要素数、`find_by_order(k)` は 0 始まりの順位を取得します。`k >= size()` では `end()` を返すため参照外しできません。降順にするため値を負にする方法は、符号付き最小値でオーバーフローし得ます。

## 入出力

`cpptemplate` の `in` / `scan` は既存の変数とサイズ確保済み `vector`・`deque`・`array`・C 配列・`pair` を再帰的に読みます。`vector<pair<...>>` などの入れ子も扱えます。コンテナのサイズは入力から増やしません。`vector<bool>` は整数の 0 を false、それ以外を true とします。入力失敗時はストリームの失敗状態を残し、読み取り済みの要素は変更済みです。`vector<bool>` の失敗した要素以降は変更しません。`paizatemplate` には `in` / `scan` の定義はありません。

`out_c` / `out_c_pairs` は両テンプレートにあり、`std::cout` に指定した区切りで出力し、空コンテナでも改行します。要素のストリーム演算が必要です。`chmax(a,b)` / `chmin(a,b)` は比較して必要な場合だけ更新し、更新したかを返します。同値なら更新しません。

## マクロと型

- 両方の `ALL(x)` は `x.begin(), x.end()` を展開し、同じ引数式を 2 回評価します。副作用のある式や一時コンテナを渡さず、コンテナ変数に使ってください。`YES` / `NO` は `Yes` / `No` と改行を出力します。
- `cpptemplate` の `ALLR` も同様に引数式を 2 回評価します。`ll`、`ull`、`ld` はそれぞれ `long long`、`unsigned long long`、`long double`、`INF` は `long long` の `10^18` です。`INF` は最大値ではなく、演算時のオーバーフローや番兵との衝突に注意します。
- `INT(a,b)`、`LL`、`ULL`、`STR`、`CHR`、`DBL` は同名の型の変数を宣言して `in` で読みます。`VEC(type,name,n)`、`VV(type,name,h,w)` はサイズ確保後に読みます。これらは複数文に展開され、単一文が必要な `if` などで中括弧なしに使わないでください。型の途中のカンマはマクロ引数を分けるため、`pair<int,int>` のような型には別名を付けます。
- `mint` は既定で ACL の `modint998244353`、`minpq<T>` は小さい値を先に取り出す priority queue です。`LOCAL` が未定義の場合の `dbg(...)` は `42` に展開され、引数は評価されません。副作用に依存しないでください。

これらの名前はグローバルスコープの識別子やマクロと衝突し得ます。必要なものだけを利用し、問題側の型・変数名と区別してください。従来の入出力・マクロの具体的な来歴は未確認です。両テンプレートのマクロ展開と、全体をファイルとして展開したコンパイル・入出力はローカルで検査します。

## 数値とペアの小さな補助

- 両テンプレートの `_pow(x,n)` は非負指数の整数累乗で、`0^0` は 1 です。`n >= 0` と乗算結果が `long long` に収まることが前提です。負の指数は `assert` で検査しますが、`NDEBUG` でも前提を守ってください。剰余を取る累乗には使えません。`_pow` は互換性のため維持していますが、先頭がアンダースコアのグローバル識別子は C++ 実装用に予約されています。
- 両テンプレートの `mnht(a,b,c,d)` は `(a,b)` と `(c,d)` のマンハッタン距離です。引数は同じ型で、各差・絶対値・和がその型に収まることが必要です。符号なし整数の減算や符号付き最小値の絶対値には注意してください。
- `cpptemplate` の `to_digit` は `uint64_t` の十進桁数を返し、0 は 1 桁、最大値は 20 桁です。負数を渡すと符号なし変換されます。`std::countl_zero` を使い C++20 が必要です。
- `pairhash` は `pair<ll,ll>` を `unordered_set` などのキーにする単純なハッシュを定義し、集合名の placeholder を持ちます。ハッシュの衝突時も集合は等価比較で区別しますが、偏った入力では性能が落ち得ます。攻撃的な入力に対する耐性は意図していません。比較元と利用条件の未確認事項は `THIRD_PARTY_NOTICES.md` を参照してください。

これらは短い競プロ用補助として snippet 内で保守し、展開後の境界テストを実施します。
