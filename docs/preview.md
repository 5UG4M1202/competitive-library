# 生成サイトのローカルプレビュー

verifier が生成した HTML を、普段のブラウザで公開せずに確認できます。Python 3.10 以降が必要です。サーバーは `127.0.0.1` のみに待ち受け、他の PC には公開しません。`file://` ではサイトの baseurl 付きリンクが動かないため、HTTP を使います。

リポジトリのルートから実行します。

```powershell
python tools/preview_site.py <生成HTMLディレクトリ>
```

表示される `http://127.0.0.1:8765/competitive-library/` を自分のブラウザで開きます。終了はサーバーを実行した端末で `Ctrl+C` です。ポート 8765 を使えない場合は `--port 8766` のように変更できます。HTML ビルド時の baseurl が異なる場合は `--baseurl /名前` を指定してください。baseurl は単一のパス要素に限ります。

トップ、各ライブラリの説明・コード例、テスト、ライセンス・通知への導線を確認してください。外部 CDN や出典リンクにはネットワーク接続が必要な場合があります。プレビューは画面確認用であり、GitHub Actions や公開済み Pages の検証ではありません。
