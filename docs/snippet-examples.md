# 操作例スニペット

これらは挿入位置の変数や処理に依存する使用例です。`cpp.json` から展開した後、入力条件と本体を問題に合わせて調整します。

整数累乗・マンハッタン距離・十進桁数・ペアのハッシュなどの小さな補助は [提出用テンプレートの使い方](template-usage.md) も参照してください。

## 二分探索 `@meguru`

`ll`、非負の `N`、C++20 の `std::midpoint` と単調な真偽条件を使います。探索対象 `[0,N)` で条件が偽から真に変わるとき、最初に真になる位置を `ok` に返します。存在しなければ `N`、`N=0` でも `N` です。初期値 `ng=-1`、`ok=N` は番兵であり、番兵に対して条件を呼びません。条件が真から偽になる問題などでは、番兵と不変条件を合わせて変更してください。

終了条件は `abs(ok - ng) > 1` です。整数版では引き算とその絶対値が `ll` に収まる必要があります。例えば `ng=-1` の場合、`N=LLONG_MAX` は差がオーバーフローするため使用できません。条件自体のオーバーフローや配列参照の範囲も利用者が管理してください。

小数の二分探索に流用する場合、`ng`・`ok`・`mid` の型と初期値を問題に合わせ、終了条件の `1` を `1e-5L` のような許容幅に変えます。`ok` は条件を満たす側、`ng` は満たさない側にしてください。端点が浮動小数点の精度の限界で動かなくなった場合も終了します。終了幅は答えの絶対誤差を決める目安で、条件の計算誤差は別です。`python3 tools/test_meguru_snippet.py` は整数と小数の境界を検査します。めぐる式二分探索の一般的な解説として [drken の記事](https://qiita.com/drken/items/97e37dd6143e33a64c8c)がありますが、スニペットの取得元は未確認です。

## 順列・組合せ

`nextperm` は `ALL` マクロと `std::sort`、`std::next_permutation` を使い、最初に対象配列を並べ替えます。重複する値は区別せず、空配列にも `do` 内の処理を 1 回行います。元の順序が必要ならコピーしてください。

`nextcomb` は `ALL`、`next_combination` と出力ストリームが必要な例です。両テンプレートには仕様から別チャットで AI に生成させた実装を収録しています。初めに範囲全体を昇順に整列し、`0 <= k <= n` としてください。先頭 `k` 要素が組合せとなり、比較上同値の組合せは重複せず辞書順に列挙されます。最後に `false` を返して全体を昇順に戻しますが、比較上同値の要素の元の順序は保証しません。空範囲・`k = 0`・`k = n` は組合せを 1 回扱えます。1 回の時間計算量は `O(n)`、追加メモリは `O(1)` です。ただしイテレーターと要素の交換が定数の作業領域を使うことを前提とし、交換処理自身による確保は含みません。範囲は変更可能なランダムアクセス範囲で、要素は `iter_swap` で交換でき、`operator<` が狭義弱順序である必要があります。旧実装と新実装の来歴は `THIRD_PARTY_NOTICES.md` を参照してください。

## 格子の方向

`dxdy4`、`dxdy8` は `x` を列、`y` を行とし、4 方向の順序は右・下・左・上です。8 方向はこの 4 方向に斜めを加えます。`@nxny` は同じ 4 方向の配列を自分で宣言し、`x,y,W,H` と有効な座標を仮定して範囲外を除きます。これらを同じスコープで重ねて展開すると `dx` / `dy` が再定義されます。範囲内でも壁かどうかは別途確認してください。

既存の [`GRID`](../library/graph/grid.md) は `(行,列)` 順で、壁を考慮した 4 方向 BFS を提供します。座標の順序が上記の例と逆なので、組み合わせるときは明示的に変換してください。
