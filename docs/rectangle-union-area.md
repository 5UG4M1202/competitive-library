# 重なりを含む長方形の面積

長方形が覆う範囲の面積は、座標の種類が少なければ二次元いもす、座標が多く疎なら走査線が選択肢です。どちらも重複部分は一度だけ数えます。面積では端点を含むかどうかは値を変えませんが、実装上は半開区間として整理します。

## 座標圧縮と二次元いもす

1. 全矩形の左右 x、上下 y をそれぞれ重複除去して並べます。
2. 圧縮した二次元配列の四隅を差分更新し、二次元累積和で各セルの被覆数を作ります。
3. 被覆数が正のセルについて、`(x[i+1]-x[i]) * (y[j+1]-y[j])` を合計します。圧縮後のセルは幅・高さが一定とは限らないため、セル数だけを数えてはいけません。

矩形数を `N`、異なる x・y 境界数を `X,Y` とすると、座標ソートを含み時間は `O(N log N + X Y)`、メモリは `O(X Y)` です。`X,Y` は最大 `2N` 程度なので、どちらも大きいと実用的でありません。固定した小さい整数格子なら圧縮しなくてもいもすを使えます。

## 走査線と被覆長

1. 各矩形について、左端で y 区間を追加、右端で同じ区間を削除するイベントを作り、x 順に並べます。
2. y 境界だけを圧縮し、現在の矩形が覆う y の合計長を維持します。
3. 隣り合うイベント x の差 `dx` ごとに、**その間に有効な被覆長 × dx** を足します。同じ x のイベントはまとめて処理します。

例えば `[0,3)×[0,2)` と `[2,4)×[0,2)` では、x の帯 `[0,2)`・`[2,3)`・`[3,4)` の被覆長はいずれも 2 なので、面積は `2*2 + 1*2 + 1*2 = 8` です。

被覆長は、y の区間木に各区間が何回覆われているかと、実際に覆われる長さを保持すると更新できます。被覆数を単純に足した値は、重複を複数回数えてしまうので使えません。区間を完全に覆う被覆数が正ならその区間の全長、そうでなければ子の被覆長の和です。イベントの追加・削除は対になり、被覆数が負にならない順序で適用します。

時間は `O(N log N)`、メモリは `O(N)` です。広い座標では差、被覆長、幅との積、面積の合計が型に収まる必要があります。`int64_t` の全範囲の長方形では、面積は符号付き `__int128_t` に収まるとは限りません。[矩形和集合面積](../library/geometry/rectangle_union_area.md) は整数矩形を渡すだけで座標圧縮から行います。対応する問題例は [Library Checker: Area of Union of Rectangles](https://judge.yosupo.jp/problem/area_of_union_of_rectangles) です。
